## Open decisions

* **Distribution name.** PyPI `ptk` is an unrelated LR(1) parser package. With an
  internal index configured as extra index, uv prefers it, but a plain PyPI setup
  installs the wrong package. The `Private :: Do Not Upload` classifier prevents an
  accidental upload to PyPI, not a wrong download. Candidates: `xcce-ptk` (import name
  and CLI stay `ptk`), `projkit`, `rigkit`, `varikit`, `jobsmith`. Check PyPI,
  Artifactory, the VS Code Marketplace and command names before deciding.
* **Package index.** Now `https://rb-artifactory.bosch.com/artifactory/api/pypi/aebe-devops-pypi-local`;
  later `xc-ce-pmt-pypi-local` on BDC Artifactory (write permission pending).

## Plan: integration into pmt

1. **Move** with history (`git subtree`/`filter-repo`) to `pmt/tools/project_toolkit/`
   (src, tests, docs, examples, install, scripts, config/ptk, `.main.ptk.yml`,
   extension, hatch hooks, `pyproject.toml`, `uv.lock`, `LICENSE.txt`).
   Keep skills and agent inside the tool folder (bundle source) and point
   `authoring_bundle.py` there; pmt's `.github/skills` serves pmt contributors.
   Convert line endings to LF (pmt pre-commit). PTK keeps its own `[tool.ruff]`.
2. **Versioning.** pmt tags releases `vYY.WW.NN`; PTK's `v*` pattern would pick
   them up. Use `ptk-v*` with `strip_prefix: ptk-v` and verify Git discovery from
   the subfolder.
3. **Build and publish.** `call-python-package-build.yaml` builds `tools/<dir>`
   folders that contain a `tox.ini` (`clean`, `build`, default test env) and has the
   index name `todo`. Add a `tox.ini` (pytest, `uv build`, `twine upload` like
   `tools/xcce_taco_helpers/tox.ini`), set the repository, wire PR/push callers and
   a release job on `ptk-v*` tags. The build image needs Python ≥ 3.12 and
   Node.js 22 (VSIX built by `hatch_build.py`).
4. **Documentation.** Add `docs/tools/project_toolkit/project_toolkit.rst`
   (`eng-tool`/`ttc-tool` metadata) to `docs/tools/index.rst`. Keep the full PTK
   docs in the tool folder and publish them separately: pmt requires snake_case
   names under `docs/`, PTK uses hyphenated names that the authoring bundle lists.
5. **Extension.** Ship the VSIX in the wheel (already done) and attach it to
   releases; an internal marketplace can follow.
6. **Installers.** Point `install.ps1`/`install.sh` to the package index and the
   final distribution name.
7. **Clean-up.** Resolve F16, F18, F19; archive the old repository.
