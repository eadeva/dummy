1 | Introduction
The Namecheck component constitutes a secondary analysis process that can enforce a naming convention. It will issue
diagnostic messages against identifiers that do not match a specified regular expression. Typically, it is configured to run
from the Helix QAC GUI, but it can also be run from the command line. It analyzes a single file at a time.
Note:
As a prior step, primary analysis must have been completed successfully.
