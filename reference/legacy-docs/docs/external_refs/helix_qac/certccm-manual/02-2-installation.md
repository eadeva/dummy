# 2 | Installation

2 | Installation
CERTCCM should be installed independently, in accordance with the installation instructions given below. Then, in order
to ensure maximum compliance, it should be applied, together with the latest versions of Helix QAC for C, RCMA and
MTA under the Analysis tab in Helix QAC’s Project Properties.
Windows Installation
The installation package for CERTCCM is supplied as an executable .exe file (for example, CERTCCM-2.0.0-
Win.exe). To install as an Administrator, right-click on the file and select Run as administrator. The default installation
path for a compliance module or component is C:\Perforce alongside Helix QAC.
Linux Installation
The installation package for CERTCCM is supplied as an executable .run file (for example, CERTCCM-2.0.0-
Linux.run). Installation can be performed as either Root or Standard User. The main difference between these
installations is the location to which the product is registered:
n Under a Root installation, the product is registered inside
/etc/Perforce.d/installed_packages
n Under a Standard User installation, the product is registered inside
~/.config/Perforce/installed_packages
