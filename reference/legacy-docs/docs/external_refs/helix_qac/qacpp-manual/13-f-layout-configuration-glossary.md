# F | Layout Configuration Glossary

F | Layout Configuration Glossary
The configuration files that control code layout use the following terms to describe code grammar.
Configuration Term
Short Description
abstract-decl-id-list
List of declarations without an identifier.
abstract-declaration
Declaration without an identifier.
abstract-declaration-
expn
Pack expansion of a declaration without an identifier.
aggr-init-clause
The initializer in an aggregate initialization.
alias-decl-stmt
Alias declaration.
aligned-name
Variable declaration in a bitfield.
alignof-expr
Alignof expression.
anonymous-class-def
Class definition without a class name.
arith-expr
Arithmetic expression.
array-abstract-
declarator
Array declaration without an identifier (e.g. array parameter of a pointer to function).
array-declarator
Declaration of an array variable.
array-expr
Expression indexing into an array.
asm-func
Assembler function definition.
asm-stmt
Embedded assembler code.
assign-expr
Assignment expression.
attr-decl-id
The identifier portion of a declaration with an optional sequence of attributes.
attr-spec
An attribute.
attr-spec-seq
Sequence of attributes.
auto-type-spec
An auto type specifier.
base-clause
Base classes for a class definition.
base-spec
Single base class in a base clause.

Configuration Term
Short Description
base-spec-expn
Pack expansion of a base class in a base clause.
base-spec-list
The list of base classes for a base clause.
binary-oper-expr
Bitwise operator expression (&, ^, etc.) with two operands.
block
Block of code nested inside a larger construct.
braced-init-list
Braced initializer list.
break-stmt
Break statement, commonly used in switch statements.
c-cast-expr
C-style cast expression, the target type is in parentheses.
cast-expr
C++ style cast expression such as static_cast<...>(...).
catch-list
The list of catch handlers after a try block.
catch-stmt
Single catch handler.
class-def
Class definition.
class-virt-spec
Class virtual specifier such as final.
cmpd-stmt
Compound statement.
comma-expr
Expression with a comma.
cond
Condition in a selection statement: either an expression or a declaration.
continue-stmt
Continue statement.
conv-operator
Class conversion function (e.g. operator bool()).
cv-spec
Const-volatile specifier in a declaration.
cv-spec-seq
Sequence of const-volatile specifiers.
decl
Any type of declaration.
decl-spec
Declaration specifier such as int, friend, static etc.
decl-spec-seq
Sequence of declaration specifiers.
decl-stmt
Declaration statement.
declaration
Declaration with identifier.
declaration-seq
Sequence of declarations
