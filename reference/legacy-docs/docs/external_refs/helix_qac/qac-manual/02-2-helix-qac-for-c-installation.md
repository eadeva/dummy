2 | Helix QAC for C Installation
The current version of Helix QAC for C is bundled with Helix QAC. Following the installation of Helix QAC, this version of
Helix QAC for C is made available as a component for selection in each project, provided that C is selected in the Source
Language Toolchain under the Analysis tab in Helix QAC’s Project Properties.
