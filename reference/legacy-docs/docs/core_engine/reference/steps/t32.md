# TRACE32 (Lauterbach)

Sessions live in `self.resources["lauterbachs"]` keyed by `T32_ID`, using `Trace32Api`. `t32_setup` sets `OS_SEPARATOR`, `T32_TMP_FOLDER`, `T32_HELP_FOLDER` env vars per platform.

```{note}
**Shape: PARAMS-DICT.** All fields below are nested under a `params:` mapping, not flat siblings
of `type`.
```

## `t32_setup`  *(game_stopper)*

- **Source:** [`t32_steps.py`](../../../../xc_ce_utils/core_engine/steps/t32_steps.py)

```yaml
t32_open:
  type: t32_setup
  params:
    T32_ID: main
    cmm_base_path: SW/trace32
    TARGET_ARQUITECTURE: tricore
    start_cmm: SW/trace32/start.cmm
    T32_HOST: localhost
    T32_API_PORT: 20000
    T32_API_PACKET_LENGTH: 1024
    keep_open: true
```

## `t32_get_state`

- **Behavior:** Queries the target state; raises `ExecutionStepError` if the target reports
  `"target in reset"`. Does **not** expose an `output_variable` field.

```yaml
t32_state:
  type: t32_get_state
  params:
    T32_ID: main
```

## `t32_run_cmm_script`

- **Notes:** Default `timeout=100`. Spurious `"A53 Wakeup error"` / `"debug port fail"` strings are tolerated.

```yaml
t32_init_target:
  type: t32_run_cmm_script
  params:
    T32_ID: main
    script: SW/trace32/init_target.cmm
    timeout: 120
```

## `t32_run_cmd`

```yaml
t32_break:
  type: t32_run_cmd
  params:
    T32_ID: main
```

## `t32_erase_flash`

```yaml
t32_erase:
  type: t32_erase_flash
  params:
    T32_ID: main
    start: 0x80000000
    end: 0x80040000
```

## Category index

| Step type | Description |
|---|---|
| `t32_setup` *(game_stopper)* | Initialise TRACE32 |
| `t32_get_state` | Read debugger state |
| `t32_run_cmm_script` | Run a CMM script |
| `t32_run_cmd` | Send a TRACE32 command |
| `t32_erase_flash` | Erase target flash |
| `t32_flash_binary` | Flash a binary file |
| `t32_flash_hex` | Flash a hex file |
| `t32_load_elf` | Load an ELF to the debugger |
| `t32_close` | Close TRACE32 connection |
