# JSON Utils

**Package:** `xc_ce_utils.json_utils`

JSON file processing, variable substitution, and script execution utilities.

---

## Key Components

### `json_utils.py`

Core JSON file operations:

| Function | Description |
|---|---|
| `load_json_file(path)` | Load JSON with UTF-8 BOM support |
| `dump_json_file(data, path)` | Write JSON to file |
| `substitute_env_variables(value)` | Replace `$ENV{VAR}` from environment |
| `substitute_variables(value, vars)` | Replace `{{ var }}` from variables dict |

Supports UTF-8 BOM handling for files generated by Windows tools.

### `json_script_executor.py`

`ScriptExecutor` class: runs external scripts defined in JSON configuration files with parameter substitution.

```json
{
  "script_path": "scripts/build_tool.py",
  "parameters": [
    {"name": "--config", "value": "Release"},
    {"name": "--target", "value": "{{ target_name }}"}
  ]
}
```

```python
from xc_ce_utils.json_utils.json_script_executor import ScriptExecutor

executor = ScriptExecutor()
executor.execute_script("config/script.json", {"target_name": "ecu"})
```
