2 | Helix QAC for C++ Installation
The current version of Helix QAC for C++ is bundled with Helix QAC. Following the installation of Helix QAC, this version
of Helix QAC for C++ is made available as a component for selection in each project, provided that C++ is selected in the
Source Language Toolchain under the Analysis tab in Helix QAC’s Project Properties.
Updating of Layout Configuration Files
If you refer to Layout Configuration Files, you will see that various files are supplied so that C++ projects can be checked
for style. These are activated using the -layoutfile,-lf option. You can specify the location for each of the files that you
provide following the -layoutfile command.
If you have just installed a new version of Helix QAC for C++ , and you wish to use these files with the new version, then
proceed as follows for each of the files:
1. Compare the .layout file supplied with the new version of Helix QAC for C++ , against the version of the file that
you were using previously.
2. Apply the required differences to the .layout file supplied with the new version, so that this can then act as the
latest style guideline.
